# Портфолио: Telegram-боты, лендинги и интеграции для малого бизнеса

Четыре демо-проекта и сайт-витрина, которая их показывает. Всё собрано так, чтобы запускаться одной командой и объясняться простыми словами.

> **Честно о содержимом.** Все компании, клиенты, цены и данные в проектах вымышленные, проекты помечены как «демо-проект». Отзывов и цифр заработка здесь нет и быть не должно, пока нет реальных клиентов.

**Что нужно заменить своим (имя, контакты, цены, токены), перечислено в [TODO.md](TODO.md).**

## Быстрый старт

Нужен [Python 3.10+](https://www.python.org/downloads/) (при установке на Windows поставьте галочку «Add Python to PATH»).

- **Боты и магазин.** Зайдите в папку проекта и запустите `start.bat` (Windows) или `bash start.sh` (Mac/Linux). При первом запуске скрипт сам создаст окружение, поставит зависимости и создаст файл `.env` из образца. В `.env` нужно вписать токен бота (бот 01 и 04). Магазин (03) запускается без токенов: <http://127.0.0.1:5050>.
- **Лендинг и витрина.** Откройте `index.html` двойным кликом.
- **Всё вместе, как на хостинге:**
  ```bash
  python scripts/build_site.py
  python -m http.server 8000 --directory dist
  ```
  Откройте <http://127.0.0.1:8000>: витрина, а по кнопке «Открыть демо» у проекта 02 откроется живой лендинг.

## Безопасность: секреты

- Токены и ключи лежат только в файлах `.env`. Они перечислены в `.gitignore` и **не попадут в git**. Образцы без секретов называются `.env.example`.
- Перед первой загрузкой на GitHub выполните проверку из раздела ниже.
- Если токен бота или ключ API всё же попал в публичный репозиторий, удаления коммита недостаточно: считайте секрет скомпрометированным и сразу выпустите новый (у @BotFather команда `/revoke`, у провайдера ИИ ключ пересоздаётся в личном кабинете).

## Как загрузить проекты на GitHub

1. Установите [Git](https://git-scm.com/download/win) и создайте аккаунт на [github.com](https://github.com).
2. На GitHub нажмите **New repository**, назовите, например, `portfolio`, выберите **Public**, **не** ставьте галочки «Add README / .gitignore» (они уже есть).
3. В папке портфолио выполните:

   ```bash
   git init
   git add .
   git status
   ```

   **Проверьте список `git status`:** в нём не должно быть файлов `.env`, `*.db` и папок `.venv`. Если они есть, остановитесь и проверьте `.gitignore`. Затем:

   ```bash
   git commit -m "Портфолио: 4 демо-проекта и сайт-витрина"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/portfolio.git
   git push -u origin main
   ```

   При первом `git push` откроется окно входа в GitHub (пароль от аккаунта для командной строки не принимается, используется вход через браузер или токен доступа GitHub).
4. Откройте `showcase/site.config.js` и замените в ссылках `your-username` на свой логин (раздел `projects`). Сделайте новый коммит и `git push`.

## Как выложить сайт-витрину бесплатно

Витрина статическая, значит ей подходит бесплатный хостинг. Сначала загрузите проекты на GitHub (раздел выше).

### Вариант 1. GitHub Pages (проще всего, уже настроено)

1. В репозитории на GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. Любой `git push` в ветку `main` запускает [workflow](.github/workflows/pages.yml): он выполняет `python scripts/build_site.py` и публикует папку `dist`. Прогресс виден во вкладке **Actions**.
3. Через 1–2 минуты сайт откроется по адресу `https://ВАШ_ЛОГИН.github.io/portfolio/`.
4. Впишите этот адрес в `showcase/site.config.js` → `seo.url` и сделайте `git push`.

### Вариант 2. Vercel

1. Зарегистрируйтесь на [vercel.com](https://vercel.com) через GitHub.
2. **Add New → Project**, выберите репозиторий `portfolio`.
3. Настройки уже лежат в [`vercel.json`](vercel.json): сборка `python3 scripts/build_site.py`, папка результата `dist`. Нажмите **Deploy**.
4. Если Vercel не сможет запустить Python-сборку, в настройках проекта укажите **Root Directory: `showcase`** (тогда сайт отдаётся как есть, но кнопка «Открыть демо» у лендинга перестанет работать: уберите её ссылку в `site.config.js`).

> Оба способа публикации описаны по документации сервисов и в этой сборке не запускались: у меня нет доступа к вашему аккаунту GitHub и Vercel. Файлы настроек проверены только локально (`build_site.py` отработал, собранный `dist` открывается в браузере). Если что-то не сработает, откройте вкладку Actions (GitHub) или логи деплоя (Vercel): ошибка там будет написана.

### Что с демо ботов и магазина

Боты и магазин требуют работающего сервера, а на GitHub Pages размещается только статика. Поэтому на витрине у них есть ссылка на код и иллюстрация, а кнопка «Открыть демо» появляется, только когда вы впишете ссылку в `site.config.js`. Варианты:

- **Боты:** запустить бота на любом сервере или домашнем компьютере и дать ссылку `https://t.me/имя_бота` в `projects.booking.demo` / `projects.assistant.demo`. Бот работает, пока запущен процесс.
- **Магазин:** выложить на бесплатный хостинг для Python (например, Render или PythonAnywhere); подробности и подводные камни в [README проекта 03](projects/03-shop-payment-demo/README.md).

## Тесты

Боты и магазин покрыты автотестами. Запуск в каждой папке проекта:

```bash
python -m venv .venv
.venv\Scripts\activate          # Mac/Linux: source .venv/bin/activate
pip install -r requirements-dev.txt
pytest
```
