# 05. Дизайн-концепция лендинга сервиса онлайн-записи «Окошко»

> **Демо-проект.** Сервис «Окошко» вымышленный, цены, тарифы и тексты демонстрационные. Это не настоящий продукт и не клиентская работа.

## Зачем это

Показывает, как я подхожу к дизайну лендинга продуктового сервиса: от структуры и идеи до готовой адаптивной вёрстки. Для заказчика это ответ на вопрос «что вы можете нарисовать и сверстать».

## Что сделано

- Структура страницы: первый экран, возможности, три шага, тарифы, вопросы и ответы, финальный призыв.
- Стиль: тёмный первый экран с градиентным фоном, один акцентный цвет (лайм), крупная типографика на системных шрифтах.
- Интерфейс продукта (расписание дня и всплывающее уведомление о записи) собран на CSS, без картинок и скриншотов.
- Блок возможностей в виде «бенто»-сетки, тарифы с выделенным вариантом.
- Адаптивность от телефона до широкого монитора.
- Доступность: фокус с клавиатуры, контрастные цвета, `prefers-reduced-motion`, вопросы и ответы на нативных `<details>`.
- Без фреймворков, без внешних шрифтов и скриптов: чистые HTML и CSS.

## Как посмотреть

Откройте `index.html` двойным кликом. Или соберите весь сайт, как на хостинге (из корня портфолио):

```bash
python scripts/build_site.py
python -m http.server 8000 --directory dist
```

Концепция откроется по адресу <http://127.0.0.1:8000/demos/saas-concept/>.

## Ограничения (честно)

- Это дизайн-концепция, а не рабочий сервис: кнопки ведут по якорям внутри страницы, формы регистрации нет.
- Макет собран сразу в коде. Если заказчику нужен макет в Figma, это отдельная работа.
