# 02. Лендинг-шаблон для локального бизнеса

> **Демо-проект.** Барбершоп «Борода» вымышленный, телефон, адрес и цены — образцы. Для реального клиента всё это заменяется в одном файле.

## Какую задачу бизнеса решает

Салону, барбершопу, стоматологии, автосервису нужен сайт, на который можно отправить клиента из карты, соцсетей или визитки: что делаем, сколько стоит, где мы и как записаться. Полноценный сайт на конструкторе или у студии — дорого и долго; страница-визитка с заявкой решает 90% задачи за 1–2 дня.

Этот шаблон — основа для таких страниц: меняются тексты, цвета, логотип и контакты, а вёрстка, форма, тёмная тема и SEO-теги остаются готовыми.

## Что внутри

- Одностраничная вёрстка: первый экран, услуги, цены, вопросы и ответы (FAQ), контакты, форма заявки.
- **Адаптивность**: телефон и компьютер, мобильное меню.
- **Тёмная и светлая тема**: по умолчанию как в системе у посетителя, есть переключатель; выбор запоминается.
- **Быстрая загрузка**: без фреймворков и внешних шрифтов (системный шрифт), всего 4 файла плюс логотип, около 40 КБ без сжатия (на хостинге с gzip в несколько раз меньше).
- **SEO**: один `h1`, структура заголовков, `title`, `description`, Open Graph, структурированные данные `LocalBusiness`.
- **Доступность**: ссылка «К содержимому», подписи полей, фокус с клавиатуры, `prefers-reduced-motion`.
- Форма с защитой от спам-ботов (скрытое поле) и обязательным согласием на обработку данных.

## Как запустить

Откройте `index.html` двойным кликом. Или запустите локальный сервер:

```bash
python -m http.server 5100
```

и откройте <http://127.0.0.1:5100>. Установка и сборка не нужны.

## Как сделать сайт под нового клиента

**Править нужно только [`site.config.js`](site.config.js).** Внутри подробные комментарии на русском:

| Раздел конфига | Что меняет |
|---|---|
| `brand` | название, логотип (картинка в `assets/` или буква-значок), подпись |
| `theme` | акцентный цвет для светлой и тёмной темы, тема по умолчанию |
| `seo` | заголовок и описание для поисковиков, адрес сайта |
| `hero` | заголовок первого экрана, кнопки, короткие факты |
| `services`, `prices`, `faq` | карточки услуг, прайс, вопросы (можно удалить раздел, оставив `[]`: блок и пункт меню исчезнут) |
| `contacts` | телефон, Telegram, email, адрес, часы работы, ссылка на карту |
| `form` | как отправлять заявки, текст согласия, ссылка на политику |
| `demoNotice` | пометка про демо сверху; для клиента поставьте `""` |

Ещё нужно:
1. Заменить `assets/logo.svg` и `assets/favicon.svg` логотипом клиента.
2. В [`index.html`](index.html) продублировать `title`, `description` и `og:*` в `<head>` (см. комментарий там): превью ссылки в мессенджерах берётся из этих строк, потому что мессенджеры не выполняют JavaScript.
3. Подключить отправку заявок (ниже).
4. Если собираете имя и телефон, добавить политику конфиденциальности и ссылку на неё в `form.privacyUrl`.

### Пример адаптации под другую нишу

В папке [`examples/dental`](examples/dental) лежит тот же шаблон, адаптированный под вымышленную стоматологию «Улыбка»: изменились только `site.config.js`, логотип и иллюстрация (`hero.art` в конфиге: `"pole"`, `"none"` или путь к своей картинке). Код (`index.html`, `style.css`, `script.js`) тот же. Так выглядит типичная адаптация под клиента.

Для предпросмотра можно добавить к адресу страницы `?theme=light` или `?theme=dark`: тема будет принудительной.

### Куда отправлять заявки

Сайт статический, своего сервера нет, поэтому заявки нужно куда-то отправить. Три способа в `form`:

1. **`endpoint`** — адрес сервиса приёма форм (Formspree, Web3Forms и подобные) или собственный сервер. Заявка уходит как JSON методом POST. Если сервис требует ключ в теле запроса, впишите его в `extraFields`. Самый надёжный вариант: заявки приходят на почту без участия клиента.
2. **`telegramFallback: true`** — откроется Telegram с готовым сообщением владельцу. Без сервера и регистраций, но посетитель должен сам нажать «Отправить», так что часть заявок потеряется.
3. Оба пустые — **демо-режим**: заявка никуда не уходит, форма об этом честно пишет. Так работает демо в портфолио.

> Заявки в «боевом» режиме на реальном сервисе в этой сборке не проверялись: проверена валидация, демо-режим и защита от ботов. Перед сдачей клиенту отправьте себе тестовую заявку.

## Как выложить

Подойдёт любой статический хостинг: GitHub Pages, Vercel, Netlify, обычный хостинг по FTP: нужно просто загрузить папку. Подробная инструкция для GitHub Pages и Vercel — в корневом `README.md` портфолио.

## SEO: что сделано и что осталось

Сделано в шаблоне: заголовки, мета-теги, Open Graph, `LocalBusiness`, `lang="ru"`, адаптивность.

Остаётся при запуске реального сайта: зарегистрировать его в Яндекс Вебмастере и Google Search Console, добавить сайт в карты (Яндекс Карты, 2ГИС, Google), указать `seo.url`, при желании добавить `robots.txt` и `sitemap.xml` (для одной страницы он простой).

## Ограничения (честно)

- Страница собирается в браузере из `site.config.js`. Google и Яндекс исполняют JavaScript и увидят текст, но мессенджеры и часть сервисов-парсеров — нет: поэтому нужен шаг 2 выше. Если нужен SEO-максимум, шаблон можно превратить в предварительно собранный HTML (отдельная доработка).
- В шаблоне нет фотографий, галереи и отзывов: настоящие фото и настоящие отзывы клиента добавляются отдельно. Не вставляйте выдуманные отзывы.
- Нет интеграции с онлайн-записью и CRM: для этого есть проект 01 (бот записи).

## Структура

```
index.html        разметка и SEO-теги
style.css         оформление, две темы, адаптив
script.js         сборка страницы из конфига, форма, тема, меню
site.config.js    ВСЕ тексты и настройки (править только его)
assets/           логотип и иконка
```
